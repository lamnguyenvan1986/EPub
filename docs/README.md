## Quy ước cập nhật tài liệu

- Thêm/sửa tính năng: cập nhật `CHANGELOG.md` và, nếu đổi cấu trúc, `ARCHITECTURE.md`.
- Sửa lỗi: thêm dòng vào `BUGFIX_LOG.md` (số thứ tự tiếp theo, file, lỗi, cách sửa, cách kiểm tra).
- Đổi cách cài đặt, build hoặc deploy: cập nhật `SETUP.md`.
- `README.md` ở gốc chỉ giữ phần tổng quan và tình trạng nền tảng.

## 🎯 **Mục tiêu Dự án**

LibriAudio là một ứng dụng đọc sách toàn diện với các tính năng:

- ✅ Đọc EPUB, PDF, MOBI
- 🔊 Text-to-Speech với giọng tiếng Việt
- 🎧 Phát audio in background
- 📌 Đánh dấu & ghi chú
- ☁️ Đồng bộ với Firebase
- 🌓 Dark mode
- 🔍 Tìm kiếm trong sách
- 📝 Playlist

---

## 🛠️ **Công nghệ Sử dụng**

| Thành phần | Công nghệ |
|------------|----------|
| Framework | Flutter |
| State Management | Provider + Riverpod |
| Database | Hive + SharedPreferences |
| Audio | just_audio + flutter_tts |
| Cloud | Google Drive + Firebase |
